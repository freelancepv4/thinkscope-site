Architecture

Structured entities first, pages second — so search, internal links and schema are generated from data.

URLs

/movies/[slug] /tv/[slug] /sports/[event] /experiments/[slug] /predictions/[slug] /ai-vs-ai/ /ai-vs-humans/ /countries/[c] /questions/[slug] /models/[m] /methodology/ /about/ /editorial-policy/ /search/. Locale prefix (/es/…) reserved, inactive, hreflang-ready.

Content models

Article, Movie, TVShow, Sport, Team, Player, Music, Game, Country, Question, Experiment, Prediction, AIModel, Analysis, Source, Result. Each has id, slug, locale, status, sources[], updatedAt, isDemo.

Graph relations

Movie → Country, Language, Genre, Analyses[], Questions[], AudienceData[], CriticData[], Experiments[], Predictions[]. Third-party data needs a Source record before display.

Templates

Movie, TV/Drama, Sport, Experiment, Article — built on shared blocks: Consensus, Agree/Disagree, VsHumans, Sources, Related, Ask.

Stack

Next.js + TypeScript + Tailwind, server-rendered, JSON-LD per page type, sitemap/robots, lazy-loaded globe. Content layer swappable for Supabase/Postgres/CMS.

Trust

Independent, unaffiliated with model vendors or studios. “Thinks” is brand shorthand: outputs are generated analyses, not consciousness or opinion.

Design system

Soft-dark / off-white hybrid. Serif editorial headings, system sans UI.
